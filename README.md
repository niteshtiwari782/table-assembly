# Dining Table Assembly · 3D Guide

An interactive 3D, step-by-step assembly guide for a flat-pack 4-seater dining table, built with [Three.js](https://threejs.org/).

**Controls:** Next/Back, replay the current step, or auto-play everything. Drag to rotate, scroll to zoom, arrow keys to navigate.

It's a static site with no build step. To run it locally:

```bash
python3 -m http.server 8000
# open http://localhost:8000
```

Deploy with GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.

Generic flat-pack design for illustration. Not affiliated with any furniture retailer.
